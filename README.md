# Career Platform

## Project Overview

This project is being developed to build a modern, trusted, fast, and user-friendly career platform.

Our goal is to help job seekers discover verified opportunities through a simple and reliable experience.

This project is currently under active development.

---

## Vision

To become one of the most trusted career platforms in Asia, and later expand globally.

---

## Mission

- Collect verified jobs from trusted sources.
- Provide a fast and simple job search experience.
- Help job seekers make better career decisions.
- Publish high-quality career resources.
- Build a platform that users trust.

---

## Core Values

- Trust
- Simplicity
- Quality
- Transparency
- User First
- Continuous Improvement
